# ask-video

Ask questions about YouTube videos using AI.

## Installation

This project uses `uv` for package management.

1.  **Install `uv`:**
    ```bash
    curl -LsSf https://astral.sh/uv/install.sh | sh
    ```
    For other installation methods, see the [uv documentation](https://github.com/astral-sh/uv).

2.  **Clone the repository:**
    ```bash
    git clone https://github.com/yourusername/ask-video.git
    cd ask-video
    ```

3.  **Install dependencies:**
    ```bash
    uv sync
    ```

## Usage

```bash
ask_video "https://www.youtube.com/watch?v=dQw4w9WgXcQ"
```
